RideHUD Web v0.3 · FIT 원본 데이터를 기반으로 계산한 수치로 Garmin Connect의 최종 요약값과 약간 다를 수 있습니다.

RideHUD 사용 방법

  1. Garmin Edge의 활동 기록 .fit 파일을 올립니다.
  2. 선택할 항목을 추가하고, 화면에서 드래그하여 자유롭게 배치합니다.
  3. 동영상 장면에 맞는 FIT 경과시간을 시작/종료로 지정합니다.
  4. WebM 또는 투명 PNG 시퀀스를 출력해 영상 편집기에 얹습니다.

투명 WebM은 모든 편집기에서 보장되지 않습니다. 검은 바탕이 나타나면 PNG 시퀀스로 출력하거나 초록 배경 WebM을 선택한 뒤 크로마키를 제거하세요. PNG 시퀀스는 편집기에서 60fps 이미지 시퀀스로 불러오면 됩니다.

무료 GitHub Pages 정적 호스팅용입니다. FIT는 사용 중인 기기에서만 읽습니다.
